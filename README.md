# Server Dashboard

Максимально простой, переносимый и надежный дашборд для Linux-серверов. Без сторонних зависимостей.

## 1. Быстрый запуск
1. Распакуйте архив на сервере
2. Сделайте скрипт исполняемым: `chmod +x install.sh`
3. Запустите: `sudo ./install.sh`
4. Откройте `http://<IP-сервера>:8000`

## 2. Установка
Скрипт `install.sh` автоматически найдет Python, при необходимости установит его системным пакетным менеджером и создаст systemd-юнит (если ОС поддерживает).

## 3. Удаление
Выполните: `sudo ./uninstall.sh`. 
Ваши инструменты (Docker, Git и т.д.) и файл конфигурации затронуты не будут.

## 4. Настройка порта
Отредактируйте `/etc/server-dashboard.env`:
```env
DASHBOARD_PORT=8080

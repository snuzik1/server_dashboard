# Server Dashboard

Максимально простой, переносимый и надежный дашборд для Linux-серверов. Не требует Node.js, сложных баз данных или сторонних Python-библиотек.

## 1. Быстрый запуск

1. Распакуйте архив на сервере.
2. Сделайте скрипт установки исполняемым: 
   `chmod +x install.sh`
3. Запустите установку от имени суперпользователя: 
   `sudo ./install.sh`
4. Откройте интерфейс в браузере: `http://<IP-сервера>:8000/`

---

## 2. Важные нюансы и решение частых проблем

### Проблема 1: Ошибка «No such file or directory» при запуске ./install.sh
Если файл точно существует, но система выдает такую ошибку, это означает, что скрипт был сохранен или распакован с Windows-окончаниями строк (CRLF). Ядро Linux не может корректно прочитать служебную строку `#!/bin/sh`.
**Решение:** Конвертируйте окончания строк в формат Unix перед запуском:
```bash
sed -i 's/\r$//' install.sh
sed -i 's/\r$//' uninstall.sh
